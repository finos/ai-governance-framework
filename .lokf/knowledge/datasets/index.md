# Datasets

* [FINOS's tree](finos-tree.md) - Every file FINOS's commit holds, unchanged at the repository's root: the pages under `docs/_risks/`, `docs/_mitigations/` and `docs/_usecases/`, the data under `docs/_data/`, the Jekyll site, and FINOS's scripts and governance files.
* [ai-governance-framework LinkML schema](ai-governance-framework-linkml-schema.md) - The LinkML model of FINOS's framework, `linkml/src/ai_governance_framework/schema/ai_governance_framework.yaml`: `Aigf` classes for the risks, mitigations and use cases, the reference files and the other data files, at FINOS's v3.
* [The catalogue](catalogue.md) - `linkml/src/ai_governance_framework/data/aigf-v3.yaml`, FINOS's v3 as one `AigfCatalogue` record: 24 risks, 25 mitigations, 4 use cases, the keys of 13 reference files, 11 classes of data and the two taxonomies.
* [SSSOM sets of citations](sssom-sets.md) - `linkml/src/ai_governance_framework/mappings/`: one SSSOM set per reference file, 13 sets and 793 rows. Each row says that a page cites an entry, as FINOS's front matter states; it is a citation, not an equivalence.
* [The adapt copy](adapt-copy.md) - `.lokf/ai-governance-framework.yaml`, the copy `lokf adapt` writes from the schema: it re-roots `AigfItem` and `AigfDataClassification` on `Concept`, and renames `version`, `name`, `url`, `source` and `references` with an `aigf_` prefix.
* [Neighbours' adapt copies](neighbour-copies.md) - `linkml/tests/neighbours/`: the adapt copies of 27 released lmodel repositories, each the schema asset of a release and pinned by its checksum, so that tests can hold this schema's names and mappings to them.
* [Example data](example-data.md) - `linkml/tests/data/`: a valid example of each class that is not abstract, and a counter-example of each constraint, each naming the place it fails on its first line, which `linkml/tests/test_data.py` checks.
* [Generated artefacts](generated-artefacts.md) - What `just gen-project` and `just gen-doc` generate from the schema: the projections in `linkml/project/`, the Python models in `linkml/src/ai_governance_framework/datamodel/` and the schema's copy in `linkml/docs/schema/`.
* [List of FINOS's files](upstream-tree-list.md) - `linkml/tests/upstream_tree.tsv`: each of the 153 files of FINOS's pinned commit, with its git object hash, which the tests and the weekly watch compare.
* [Departures from FINOS's own statements](departures.md) - `linkml/tests/departures.yaml`: where FINOS's files break a statement of FINOS's own: a use case category `docs/_config.yml` does not list, and a citation of a superseded entry. A new departure fails a test.
